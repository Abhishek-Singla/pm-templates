# PM templates

Blank, reusable templates for day-to-day product management work. Copy a file, fill in the `<placeholders>`, delete the guidance lines.

| Template | Use it for |
|---|---|
| [PRD](templates/prd.md) | Defining a feature: problem, users, scope, requirements, success metrics |
| [BRD](templates/brd.md) | Capturing business needs and approvals before a PRD |
| [User story](templates/user-story.md) | One story with acceptance criteria and edge cases |
| [UAT test cases](templates/uat-test-cases.md) | Business sign-off tests before release |
| [Release notes](templates/release-notes.md) | Telling users and support teams what changed |
| [Gherkin spec](templates/gherkin-template.md) | Behaviour specs that both frontend and backend teams can build and test against |

All templates are generic. They contain no company, client or customer data.
